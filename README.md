# Creating-Groups

**Objective: Create security and distribution groups.**

1. For example, to create a group in HR: Right-click > New > Group, then enter (e.g. #HR_Department).
2. Put a symbol in front of the group name, it will be easier to search
3. Then choose Global and Security, then click OK
4. Now, let’s add John Doe to the HR Department.
5. Click on Joe Doe >member of> Add > type #HR_Department then click OK.
